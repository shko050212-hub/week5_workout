주요 기능

  • 실시간 셔틀 위치 관제: GPS와 지도 API를 활용한 버스 실시간 이동 경로 확인
  • 승하차 안심 알림: 학생 탑승/하차 시 학부모 대상 실시간 푸시 메시지 전송
  • 원생 및 노선 관리: 학원 관리자용 탑승 명단 관리 및 셔틀 운행 노선 최적화

사용 기술

Frontend: React Native, Expo
Backend: Node.js, Express, Flask API
Database & Infra: SQLite, Nginx, Docker Compose, Kakao Mobility API
